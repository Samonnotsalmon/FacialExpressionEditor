# FEE-016 表情の新規作成後に編集前のプレビューが表示される不具合

- 状態：完了
- 完了日：2026-11-19

## 背景・要望

表情編集画面を開いたまま別の表情を新しく生成すると、編集前の状態のプレビューが表示される。

## 決定した方針

編集済みの内容を保存・新規作成後も正しく画像キャッシュへ反映する。表情の値や新規作成元の仕様は変更しない。

## 完了記録

- 原因：ThumbnailKeysが過去のinstance IDとdirty countの組み合わせを保存していた。アセット保存でdirty countが0に戻り、編集前の内容ハッシュと画像が再利用されていた。Unityで値80のクリップに値10時点のキーが返ることを再現。
- 変更内容：オブジェクトごとに最新のハッシュだけを保持し、dirty countに加えて保存アセットの依存ハッシュを確認。編集後にプレビューを描かず保存した場合も検出する。メニューアイコンにも同じ修正が適用される。
- 検証結果：Unityコンパイル・Consoleエラー0。PreviewSaveCacheChecksの12項目成功（保存前後、途中のプレビューなしの保存、実際の新規表情作成を3回、元カーブ保持、Undo/Redo、Redo後の保存）。検証用アセットは削除済み。
- 残課題：実際のユーザー操作による見た目の確認は未実施。キャッシュの不一致はUnity上の再現・回帰検証で解消を確認。
