# FEE-022 表情メニューの階層と差し替え可能な標準アイコン

- 状態：完了
- 完了日：2026-11-26

## 決定事項

- Nakiyaの用途別階層・操作アイコンを参考にする。画像そのものはコピーしない。
- ユーザー指定順：「表情セット → 表情選択 → パーツ → 視線操作 → 設定」。
- セットが2つ以上の場合だけ表情セットフォルダを生成。使用できるパーツがない場合はパーツフォルダを生成しない。視線操作の有効時のみ表示する既存仕様も維持。
- パーツ内の分類・順序、表情選択内の既存フォルダ、パラメーターの値と動作は保持。
- 標準は白いシルエット・透過背景。表情・パーツの顔写真は維持。セット切り替えにはチェック記号を使う。
- 入口・表情セット・表情選択・パーツ・視線・設定・解除・瞬きOFF・次へ・分類フォルダ・チェック・ダンス・手動ON・Base写真なし時の14役割。
- 「メニュー・ジェスチャー → ゲーム内メニューのアイコン」で役割別のTexture差し替え。表情設定に保存、Undo対応、未指定なら標準。同じ役割の項目に共通で反映。
- 標準画像はコード内の形状から128pxのRGBA画像を生成。Unity Editor内蔵画像や元アバターのアセットに依存しない。ビルド用複製を保存し、写真の事前撮影なしでもPlayモードで利用できる。

## 検証

- Unityコンパイルエラー0。
- MenuHierarchyIconChecksの42項目：全14アイコンの白色・透過、セット数0／1／2／10による階層、パーツの有無、順序、差し替え、標準復帰、写真維持、ページ送りを確認。
- MenuSymbolBuildChecksの9項目：Nakiyaのコピーを使った通常のNDMFビルド、階層、入口・操作アイコン、元Descriptorの保持を確認。
- 既存のManualEyeLookChecksはビルド後の視線クリップのカーブ比較で停止。今回のシーンで出力された正面クリップのカーブは空で、旧テストが前提とするBodyの8カーブと一致しなかった。視線の実動作を今回確認済みとはしない。メニューに限定したビルド確認は成功。
- 追加指示で戻す矢印を左向きの矢印と円弧の形へ修正し、画像出力で確認。
- 標準アイコン一覧をUnityから出力して目視確認。検証用オブジェクトを破棄し、元DescriptorのJSON一致を確認。
- Nakiyaプロジェクト内パッケージへ反映。ユーザーの元メニュー・表情設定は変更していない。
- VRChat実機、差し替え欄の実画面操作は未検証。コミット・push・公開は未実施。
