# FEE-028 共通メニューアイコンをパッケージに同梱

- 状態：完了（2026-11-28）
- 発行日：2026-11-28
- 関連：[FEE-022](FEE-022.md)、[FEE-025](FEE-025.md)

## 決定仕様・変更

- 標準の白い記号14種類をRuntime/Icons/Menu/NSL_*.pngとして同梱。GUID付きの画像アセットを全設定・Prefabで共有する。
- メニュー生成とビルドで標準画像を描画・複製しない。設定ごとのIcons/Menuへもコピーしない。
- 表情・パーツの写真は従来どおり、更新時に生成・保存する。
- 手動で指定した画像やNoneは維持する。
- 既存出力は次回「MAメニューを更新してPrefabへ保存」で同梱画像の参照へ切り替わる。以前の自動生成PNGは参照切れやUndoへの影響を避けるため自動削除しない。
- 画像制作時だけ使うRenderと書き出し用テストスクリプトは残す。通常のエディタ操作では描画しない。
- Nakiyaに入っていたパッケージは公開済みv0.7.0とソース一致（独自変更なし）を確認し、v0.9.0をベースに開発変更を反映。Assets内の表情設定やPrefabは変更しない。

## 検証

- Unityコンパイルエラー0。
- SharedMenuSymbolChecks：18項目成功。14種類の共有参照、設定別画像フォルダを作らないこと、別Prefab間の参照一致、Prefab保存後のパッケージ参照、手動差し替え保持。
- MenuHierarchyIconChecks：42項目成功。PNGの白色・透過、メニューの階層・省略条件・写真保持・ページ分割を確認。
- EditableMenuBuildChecks：通常NDMFビルドの11項目成功。アイコン・メニュー構成の保持と元Descriptor・Hierarchyの不変を確認。検証コピーに元の出力済みメニューが残らないようテスト準備を修正。
- 新規画像14枚のmetaとGUID重複なしを確認。PNG合計26,681 bytes。
