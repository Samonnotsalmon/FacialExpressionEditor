# FEE-018 クリップライブラリからジェスチャー枠へのドラッグを修正

- 状態：完了
- 完了日：2026-11-23

## 背景・要望

別アバターのプロジェクトに導入した0.7.0で、左側のクリップライブラリからジェスチャー枠へアニメーションを割り当てられない。

## 決定した方針

ドラッグを開始したセルがマウス入力を保持し、スクロール領域やポインターの移動速度に左右されず開始できるようにする。割り当てとUndoの既存仕様は維持する。

## 完了記録

- `HandleDragSource`でコントロールIDと`hotControl`を使用。押した位置から6ポイント移動したらドラッグを開始し、開始元セルの外への移動も受け付ける。
- MouseUp・DragExited・Escapeで候補と入力保持を解除する。
- Unity 2022.3.22f1のNakiya_+headプロジェクトで検証用に表情設定を複製。修正前は実際のマウスドラッグで左Fistへ割り当てられないことを再現。修正後は左FistへA_faceanim1、右FistへA_faceanim2を割り当てられることを確認。
- 右FistのUndoで未割り当てへ戻り、Redoで同じ表情へ戻ることを確認。コンパイルエラー0。検証初期の非永続設定によるパス・レイアウト例外は、検証用設定をアセット化して解消。
- 元の表情設定は検証前後のJSON一致を確認。検証専用シーンとアセットを削除し、元のアバターへ表示を戻した。
- 現在のNakiya_+head内のパッケージにも修正を適用済み。変更前のソースはLibrary/FacialExpressionEditor/HotfixBackups/FEE018に保存。GitHub公開版はまだ0.7.0。
