# FEE-009 既存パーツのドラッグによるフォルダ移動・並べ替え

- 状態：完了（2026-11-16）
- 発行日：2026-11-16
- 関連：FEE-006への追加要望

## 仕様

- 既存パーツを通常フォルダ見出し（閉じていても可）へドロップすると末尾へ移動。
- フォルダ内のパーツへドロップするとその直前、追加枠へドロップすると末尾へ移動。
- フォルダなしの追加枠へドロップすると所属を解除。
- 排他グループの所属は変更しない。同じ排他グループ内では並べ替え可能。
- 元クリップを複製せず、所属と順序をまとめてUndo可能にする。
