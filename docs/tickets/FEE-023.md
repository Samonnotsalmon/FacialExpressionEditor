# FEE-023 Hierarchy順に従うメニュー配置

- 状態：完了（2026-11-28）
- 関連：[FEE-022](FEE-022.md)

## 要望・仕様

FEEの「表情」を先頭固定にせず、Hierarchyの配置で順番を調整できるようにする。

- ビルド用Menu InstallerをFEEコンポーネントのあるオブジェクトの子に生成し、MAのHierarchy順の列挙に従う。
- FEEのPrefabとExtract Menuの「Avatar Menu」を同じ親の下に配置。FEEが上なら前、下なら後ろに追加する。
- 元Hierarchyは変更しない。2026-11-26の先頭へ強制配置する実装を置き換えた。
- Installer単位で順番を扱う。Avatar Menuの子にFEEを入れて展開済みの個別項目間に挿入する使い方は対象外。
- Descriptorメニューに直接項目が残る場合、それが追加分より先になるMAの仕様を維持。
- アバター本体へFEEコンポーネントを付けると子のInstallerより先になる。並べ替える場合は独立した子オブジェクトを使用する。
