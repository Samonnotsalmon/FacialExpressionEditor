# FEE-011 表情編集画面の名前変更機能を取り除く

- 状態：完了（2026-11-18）
- 発行日：2026-11-17
- 更新日：2026-11-17
- 推奨順：11
- 関連・前提：[FEE-004](FEE-004.md)で追加した表情編集画面の名前変更UIを見直す。

共通方針は[チケット一覧](README.md)を参照。2026-11-18の次作業指示に基づき実装。

## 背景・要望

- ユーザーから、エディタ上では名前変更をすでにEnterで確定できていたとの報告あり。
- 名前変更は既存のエディタ側の操作で行えるため、表情編集画面からは名前変更機能を取り除きたい。

## 決定した方針

- 表情編集画面の「名前変更」ボタンと、それに付随する入力欄・確定・取消のUIを取り除く。
- エディタ側の既存の名前変更機能とEnterによる確定は維持する。
- 編集対象がわかる名前の表示は残す。
- 表情の編集・保存機能は維持する。「変更をなくす」の対象は名前変更UIであり、表情自体の編集機能ではない。
- 名前変更のEnter対応を新たに追加する作業は行わない。
- FEE-004の実装履歴は残し、表情編集画面の名前変更UIについては本チケットの方針を優先する。

## 作業内容と確認観点

- 表情編集画面の名前変更UIと専用の入力状態・イベント処理を整理する。他の画面で使用する共通の名前変更処理は維持する。
- 名前変更UIを取り除いた後の上部レイアウトを整え、不要な空白を残さない。
- エディタ側の既存操作で名前変更とEnter確定ができ、元ファイル名・関連する表示名への反映が従来どおり行われることを確認する。
- エディタ側で変更した名前が表情編集画面にも適切に反映されることを確認する。
- 表情編集画面で編集対象の名前を確認でき、表情の編集・保存が引き続き行えることを確認する。
- 未保存の編集内容、アニメーション参照、ライブラリの非表示設定を損なわないことを確認する。
- 変更に合わせて関連テスト・操作説明を更新し、必要なコンパイル・動作確認を行う。

## 方針変更の記録

- 当初は「名前変更をEnterキーで確定する」として発行した。
- エディタ側で既に確定できるとの報告を受け、一旦保留した。
- ユーザーの追加指示により、表情編集画面の名前変更機能を取り除く内容へ変更し、未着手として作業一覧に戻した。

## 完了記録

- 決定した仕様：上記方針。編集対象の選択欄に現在の名前を表示し、メインエディタ側で名前を変更する。
- 変更内容：編集ウィンドウ上部の名前変更ボタン・入力行・確定／取消・専用状態を削除。対象切り替え時の不要なリセットも除去。共通の名前変更処理とメインエディタのDelayedTextFieldは変更せず、Enter確定を維持。マニュアルを更新。
- 検証結果：Unityコンパイル・Consoleエラー0。ClipRenameChecks 25項目成功（メインエディタの変更処理、開いている編集画面の名前反映、同一クリップ参照、未保存カーブ・非表示状態の保持を含む）。MaterialInspectorChecksで表情／パーツ双方の編集記録が成功。実画面で上部の名前表示・対象選択が残り、ボタンと入力行が消えていることを確認。Enterの実キー入力は今回自動化せず、既存DelayedTextFieldが維持されていることをコードで確認。
- 残課題・関連チケット：本件の残作業なし。FEE-014以降は今回未着手。GitHub公開は未実施。
