# FEE-012 パーツメニューを分類ごとの階層に分ける

- 状態：完了（2026-11-17）
- 関連：FEE-006、FEE-010

## 決定した仕様

- ユーザー追加指示により、ゲーム内メニューを「パーツ → 通常フォルダ／排他グループ → パーツ」にする。FEE-010時点の平坦なメニュー構成を変更。
- 分類順はFEE-010の保存順を使い、分類内はパーツ順を維持する。未設定なら通常フォルダ、排他グループの既存表示順を使う。
- 「すべてOFF」とフォルダなしのパーツはパーツメニュー直下。空の分類は省略。件数が上限を超えた場合は既存の「次へ」でページ分け。
- パーツのアイコン、パラメーター名・値、排他動作を維持する。実アセットのフォルダは移動しない。

## 完了記録

- GenerateMenuPassで分類ごとのサブメニューを生成。順序設定がない既存設定にも階層を適用。
- PartCategoryBuildChecksを階層検証へ更新。実アバターの検証用コピーでNDMFビルドし、12項目成功。通常フォルダ2件・排他グループ2件の分類順、各分類内のパーツとパラメーター値、未分類とすべてOFFの配置、元設定不変を確認。
- Unityコンパイル・Consoleエラー0。検証用コピー・アセットは削除済み。
- GitHub公開・VRChatへのアップロードは未実施。Playモードで生成済みのメニューは、停止して再度Playすると更新される。
