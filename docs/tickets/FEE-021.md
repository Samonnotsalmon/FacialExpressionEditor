# FEE-021 視線設定を割り当て・生成の選択式に整理

- 状態：完了
- 完了日：2026-11-25
- 関連：[FEE-019](FEE-019.md)、[FEE-020](FEE-020.md)

## 決定事項

- 他アバターに同じFX構造があるとは限らないため、元FXからの自動取り込みは行わない。ボタンと候補解析コードを削除。
- 「設定方法」で「クリップを割り当てる」「Eye Lookから生成する」を選択する。選択は表情データ単位で保存しUndo対応。
- 割り当て方式では5方向のクリップを編集可能。生成方式では生成ボタンと現在のクリップの読み取り専用欄を表示。
- 方法を切り替えただけでは既存のクリップを変更しない。既存データは割り当て方式として表示する。
- ビルドと実行時の視線制御は変更しない。

## 参考記録：Nakiyaの視線メニュー

2026-11-24にNakiyaのFX・メニューを読み取り確認した事例。他アバターへの一般化や自動解析対応を意味しない。

- 「Face Menu → Eye Control」にEyeLook ON/OFFとTwoAxisPuppetのEyeLookがある。
- ON/OFFはNa_EyeLook_Cont、2軸はNa_LookA・Na_LookB。
- Eye_lookはSimpleDirectional2D。中央・上・下・左・右にEyeLook_straight／up／down／left／rightを配置。
- 視線はBodyの瞳移動用シェイプキーで制御。正面に全8項目の初期値を記録し、各方向にはその方向の左右2項目のみを記録している。
- Eye LookレイヤーのTrackingControlが自動視線とアニメーションを切り替え、Eye Look Controlレイヤーが視線レイヤーの重みを切り替える。
- これらは設計の参考資料として保持する。現在のFEEの利用手順は、クリップの手動割り当てかDescriptorからの生成。
