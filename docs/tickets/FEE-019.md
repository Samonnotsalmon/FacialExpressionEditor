# FEE-019 手動の視線操作メニューを追加

- 状態：完了
- 完了日：2026-11-24

## 背景・要望

NakiyaのFX分析を受け、視線を上下左右に動かすメニューから導入する。

## 決定した方針

- 手動ONの間は目線を優先し、OFFで元の視線制御へ戻す（ユーザー承認済み）。
- 表情設定ごとに有効化。既存設定は初期OFF。
- 正面・上・下・左・右のクリップを指定。元FXの自動取り込みは後続の[FEE-021](FEE-021.md)で撤回し、Nakiyaの仕組みは参考情報のみ記録する。
- 先頭時刻の値を使用。各方向の未記録項目は正面の値で補い、元クリップは変更しない。正面には全方向の記録項目が必要。
- メニューは「表情 → 視線操作 → 手動操作ON／目線」。同期するBoolとFloat×2は初期0・保存なし。
- 表情や元のFX／他Playableの視線指示をビルド時に内部パラメーターへ変換し、現在の視線要求を保持する。手動中に変更されても自動追従へ戻さず、手動OFF時は最新の要求へ復帰。口などの指示は保持する。
- OFFは生成レイヤーの重み0で既存アニメーションへ制御を返す。FX全体を停止する既存のMMD方式では手動操作も停止する。

## 検証

- Nakiya_+head / Unity 2022.3.22f1。元アバターのコピーに一時設定を追加してNDMFビルド。
- ManualEyeLookChecksで候補読込、未指定拒否、疎なカーブの補完、メニュー・同期パラメーター、Tracking指示の集約、ON/OFFの復帰条件を確認。
- 生成AnimatorをPlayableGraphで評価し、正面・上下左右の8シェイプキーの値、手動ON・OFFの遷移を確認。VRChatのTracking／LayerControl Behaviour自体は生成設定を検査（実機実行は未検証）。
- 初回の検証用設定は瞬き未指定によりビルドが拒否されたため、既存Blink_Enableを指定して再検証。非表示アバターの評価ではカリングで更新されなかったため、検証コピーのみAlwaysAnimateにして実値を確認。
- 検証用コピー・一時設定はfinallyで削除。元DescriptorのJSON一致を確認。
- Nakiyaプロジェクト内のパッケージにも実装を反映。現在のCoreシーンにはFEE設定が配置されていないため、利用者の設定を新規作成・変更してはいない。
