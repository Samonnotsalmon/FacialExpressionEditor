# FEE-024 アイコンを編集できるMAメニューの出力

- 状態：完了（2026-11-28）
- 発行日：2026-11-28
- 関連：[FEE-022](FEE-022.md)、[FEE-023](FEE-023.md)

## 決定した仕様

- 表情エディタの「メニュー・ジェスチャー」内に「MAメニューを生成・更新」ボタンを追加。
- 編集モードでHierarchyのFEE、またはPrefab ModeのFEEから出力。Projectで選んだPrefabアセットはPrefab Modeで開く。
- FEEの子にNSL_表情メニュー（MA Menu Installer＋Menu Group）を作り、その下にMA Menu Itemを生成。サブメニューはChildren方式。
- MA Menu ItemのIconを編集できる。画像の差し替えと明示的なNoneを更新後も保持。名前・階層・パラメーターはFEEの設定を正本として再生成する。
- 項目の内部IDで照合し、改名・並べ替え・ページ移動後もアイコンを保持。親の分類を移動した場合は、一意に対応する項目の差し替えを引き継ぐ。
- 画像は設定フォルダ下のIcons/MenuへPNGとして保存。画像の内容によって重複を避ける。Undoでは画像ファイルを削除しない。
- 出力済みメニューがある場合、ビルド時はメニューを追加生成せず、パラメーターだけを生成。
- 構成変更後やMAで内部パラメーターを手動変更した場合は、ビルド時に更新を案内して停止。写真や標準画像の更新もボタン操作で行う。
- 更新操作はUndo/Redoに対応。Prefabに保存済みの出力をシーンのインスタンスから更新する場合は、Prefab Modeでの更新を案内する。アイコンのインスタンス上の差し替えは可能。
- FEE-023のHierarchy順を維持。既存の元アバターは自動変換しない。

## 検証

- Unityコンパイル成功。
- EditableMenuExportChecks：ページ分割、画像差し替えとNone、古い構成の検出、改名・並べ替え・ページ移動、Undo/Redo、Prefab再読込後の画像永続化、旧形式セットのID安定性を確認。
- EditableMenuExportChecks：13項目成功。
- EditableMenuBuildChecks：検証コピーの通常NDMFビルドで11項目成功。顔写真生成を有効にした出力を使用し、メニューが1つであること・順番・操作アイコンの保持・元DescriptorとHierarchyの保持を確認。
- MenuHierarchyIconChecks：従来の自動生成について42項目成功。
- Nakiyaプロジェクトのパッケージへ反映済み。元アバターへの出力ボタン操作は行っていない。
