# FEE-020 Avatar Descriptorから視線クリップを自動生成

- 状態：完了
- 完了日：2026-11-24
- 関連：[FEE-019](FEE-019.md)

## 要望・仕様

元アバターに視線メニュー・クリップがなくても、Avatar DescriptorのEye Look設定を使って手動視線操作を導入できるようにする。

- 「まばたき・口 → 視線操作メニューを追加」に「Avatar DescriptorのEye Lookから生成」を追加。
- Eye Lookが有効で、目のボーンと5方向の回転が設定されている場合に生成。片目も可。シェイプキーによる視線の自動生成は今回の対象外。
- SDKの左右それぞれのローカル回転をQuaternionカーブで保存。正面とQuaternionの符号を揃える。目以外の回転・位置・スケールは記録しない。
- 表情データと同じフォルダ内のEyeLookへ5つの.animを新規保存し割り当てる。再生成は別名で既存クリップを保持。アニメーション名にNSL_は付けない。
- 割り当てはUndo/Redo対応。Undoしても生成ファイルは残す。Descriptor・目のTransformは変更しない。
- 無効なEye Look、両目未指定、重複ボーン、アバター外のボーン、未初期化回転、不正Quaternion、未保存設定はエラーで案内。

## 検証

- Unityコンパイルエラー0。
- EyeLookDescriptorChecks：元メニュー・FXのない検証用アバターで5方向生成。左右別角度と回転した親階層を使い、SampleAnimationによる実際のローカル回転を照合。保存先、再生成時の保持、Undo/Redo、片目、未設定・不正入力を確認。
- 検証用データは削除。Nakiyaプロジェクト内のパッケージへ実装反映済み。ユーザーの既存クリップ割り当ては変更していない。
- VRChat実機での目線操作は未検証。コミット・push・バージョン更新は未実施。
