# FEE-010 パーツの通常フォルダ・排他グループの表示順を変更する

- 発行日：2026-11-16
- 推奨順：一覧で管理

## 背景・要望

- パーツ分類のフォルダ自体も並び替えたい。
- ユーザー確認済み：通常フォルダと排他グループの両方を対象とする。
- FEE-009のパーツ単位の移動・並べ替えに加え、フォルダ／グループの見出し単位で表示順を変更できるようにする。

## 決定した方針

- 後続変更：FEE-012で、ゲーム内メニューも分類ごとのサブメニューに変更。以下の完了記録はFEE-010完了時点の仕様。

- 2026-11-17確認：通常フォルダと排他グループの混在順を、見出しドラッグで変更する。フォルダなしは先頭固定。表情設定ごとに保存しUndo/Redo対応。ゲーム内のパーツメニュー順にも反映する。

- 通常フォルダと排他グループの両方で、表示順の変更に対応する。
- 対象はパーツ画面内の分類表示。実ファイルやアセットフォルダの配置は変更しない。
- 並び替えによってパーツの所属、排他設定、アニメーション参照を変更しない。

## 採用した操作

- 見出しをドラッグして並び替える。挿入先を表示し、閉じた状態でも操作できるようにする。
- 表示順は表情設定ごとに保存し、開き直しても維持する。
- 並び替えをUndo/Redoに対応させる。

## 発行時の確認・検討事項（決定結果は完了記録）

- 通常フォルダと排他グループを混在した順序にできるようにするか、それぞれの区分内でのみ並び替えるか。「両方を対象」は混在配置の確定を意味しない。
- 「フォルダなし」の表示位置も変更対象とするか。
- 操作方法と順序の保存方法。
- 新規フォルダ・排他グループの追加位置、名前変更・削除時の順序の扱い、既存データで順序未設定の場合の表示。
- 画面内の表示順のみを変えるか、生成されるメニュー順にも反映するか。

## 作業内容と確認観点

- 最新の分類表示とFEE-009のドラッグ操作を確認し、見出しの並び替えとパーツ移動が競合しないようにする。
- 決定した範囲で通常フォルダ・排他グループの表示順を変更できることを確認する。
- 並び替え後もパーツが欠落・重複せず、所属・フォルダ内のパーツ順・排他動作・参照が維持されることを確認する。
- 保存・再読み込み、設定切り替え、Undo/Redoは採用した仕様に応じて確認する。
- フォルダの開閉・名前変更・解除、既存パーツのドラッグ移動が引き続き動作することを確認する。
- 生成メニューへの影響を確認し、決定した反映範囲と一致させる。

## 完了記録

- 決定した仕様：通常フォルダ・排他グループを混在して並べ替える。見出しラベルをドラッグし、移動先見出しの直前へ挿入。最下部のドロップ領域で末尾へ移動。「フォルダなし」は先頭固定。閉じた見出しでも操作可能。表情設定ごとに保存しUndo/Redo・専用複製に対応。ゲーム内メニューは分類順で項目を並べ、分類内は従来のパーツ順を維持。新しいサブメニューは作らない。
- 変更内容：分類順をパーツ本体の順序から独立して保存。通常フォルダの名前変更は位置を保持、解除時は順序情報も除去。保存済み順序にない分類は末尾へ追加。空になった排他グループは表示せず、同名で再使用すると保存位置を再利用。順序未設定の既存データは従来の表示・メニュー順を維持。分類編集で順序を保存した後は新しい順序を適用。パラメーター名・値、所属・排他動作・実ファイル配置は変更しない。
- 検証結果：PartCategoryOrderChecks 17、PartCategoryBuildChecks 6、PartFolderChecks 14、PartDragChecks 13の計50項目成功。実アバターの検証用コピーでNDMFビルドし、生成メニューの項目順とパラメーター値を照合。検証用ウィンドウにGUIイベントを送り、見出しクリック開閉・閉じた見出しへの混在並べ替えの2操作を確認し、変更後の実画面も確認。OSの物理ドラッグ全行程の検証とは区別する。コンパイル・Consoleエラーなし。
- 残課題・関連チケット：検証用データは削除。元設定は変更せず、GitHub公開は未実施。FEE-011は保留のまま。
