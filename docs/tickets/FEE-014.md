# FEE-014 表情編集中にマテリアル値のアニメーション記録を削除する

- 状態：完了（2026-11-18）
- 発行日：2026-11-18
- 推奨順：一覧で管理
- 関連：[FEE-013](FEE-013.md)（マテリアル編集の既存修正を維持する）。

共通方針は[チケット一覧](README.md)を参照。2026-11-18の作業指示・範囲確認に基づき実装。

## 背景・要望

- 表情編集中にマテリアルの値を変更した後、変更をやめたい場合がある。
- ユーザーの所感では、アニメーションに含まれたキー自体を削除できないように感じる。現在の機能不足・不具合か、操作が見つけにくいのかは未確認。
- シェイプキーと同じように、マテリアル値についてもキー自体を消去できるようにしたい。

## 決定した方針

- 2026-11-18確認：項目全体と成分単位の解除に対応。特定時刻だけの削除は対象外。複数時刻の記録がある場合は全時刻解除の確認を表示。画像・マテリアル差し替えは対象外。

- 対象は表情編集画面で変更するマテリアルの値。
- 値を0や初期値に設定するだけではなく、対象の値がそのアニメーションから指定されていない状態に戻せるようにする。
- シェイプキーの記録削除と操作の一貫性を持たせる。
- 対象外のマテリアル値、シェイプキーなどの記録や、元のマテリアルアセットを変更しない。

## 検討案（未確定）

- 記録済みのマテリアル項目に、シェイプキーと同様の削除操作を設ける。
- 記録済みか未指定かを項目ごとに確認できるようにする。
- 削除操作をUndo/Redoで戻せるようにする。

## 確認・検討事項

- 現在のシェイプキー・マテリアル編集の記録削除操作と保存方式を確認する。既存機能がある場合は、その操作を見つけやすくする必要性も検討する。
- 数値、色、ベクトルなどの削除単位。特に色の透明度だけを削除する場合、RGBの記録を巻き込まないようにする。
- マテリアル差し替え・テクスチャ参照の記録も対象に含めるか。今回の要望からは未確定。
- 複数時刻のキーを持つクリップの場合、単一時刻の削除とプロパティ全体の記録解除をどう扱うか。目的は対象値を未指定に戻すことであり、後続キーを無断で削除する仕様にはしない。
- 削除後のプレビューで参照する値と、保存・キャンセル時の反映方法を既存の編集仕様に合わせる。

## 作業内容と確認観点

- 開発仕様の「アニメーションの記録範囲と未指定値の扱い」を確認してから実装する。
- 削除後、対象の記録が残っていないことを保存・再読み込み後も確認する。初期値を記録しただけの状態と区別する。
- 削除直後のプレビューに削除前の値が残らず、未指定状態として適切に表示されることを確認する。
- 対象外のプロパティ、色の他成分、他のRendererの記録、元マテリアルを維持することを確認する。
- マテリアル透明度の既存修正（FEE-013）を壊さないことを確認する。
- 再編集・再記録ができ、採用したUndo/Redoや保存・キャンセルの仕様どおりに動くことを確認する。

## 完了記録

- 決定した仕様：数値・色・ベクトルの項目全体または記録済み成分単位を解除。対象成分の全時刻を削除し、複数キーがあれば定数カーブも含め確認する。単一時刻・画像参照・マテリアル差し替えは対象外。Undo/Redo対応、保存方式は従来のクリップ直接編集とUnity保存を維持。
- 変更内容：既存の全体解除をタブ上部の「記録済みのマテリアル値・記録解除」に移動し初期展開。「×」は全体、「成分…」はR/G/B/A・X/Y/Z/Wを選択。元マテリアルは変更せず、対象カーブをnullにして未指定化。パーツ使用項目も追従。解除後に一時Inspectorとプレビューを更新。ルートRendererの表示情報取得も対応。
- 検証結果：MaterialRecordRemovalChecks 14項目成功（全体／α／数値、他成分・他Renderer保持、Undo/Redo、保存再読み込み、実プレビュー復元、再記録）。MaterialColorCompletionChecks 11項目とMaterialInspectorChecksも成功。実画面で上部一覧・全体解除・成分ボタンを確認。確認ダイアログは複数キー判定を検証し、実データの削除操作は行っていない。コンパイル・Consoleエラー0。
- 残課題・関連チケット：本件の残作業なし。FEE-015は未着手。GitHub公開は未実施。
