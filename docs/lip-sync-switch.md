# リップシンク対象の設定

アバター内の顔メッシュを登録し、**誰を音声に合わせて喋らせるかだけ**を切り替えます。
メッシュの表示ON/OFFは、MAなどで個別に設定してください。本機能は表示メニュー、表示用パラメーター、GameObjectのON/OFFアニメーションを生成しません。表示状態による自動切り替えも行いません。

## 設定場所と保存先

HierarchyでFacialExpressionAvatar（表情設定）を選択します。Inspectorで機能ON/OFF・初期の発話先・顔メッシュを指定し、「詳細・撮影設定を開く」で口形・パターン・メニュー・写真を編集します。「まばたき・口」タブには表示しません。

共通設定はExpressionSetではなく、表情設定Prefab専用のProfile（設定フォルダのSettings内）に保存します。編集した共通設定は「Prefabへ保存」で反映してください。Play・ビルドは保存済みの共通設定を使います。同じPrefabを使う他の配置先にも反映され、別の場所で開いている下書きには更新通知を表示します。「Prefabから読み直す」で未反映の編集を破棄して読み直せます。

顔メッシュの割り当てだけは、Inspectorから各配置先へ即時反映します。新しく配置したときはアバター内の同じ相対パスを探しますが、見つからない場合は手動で指定してください。ほかのアバターのメッシュは指定できません。撮影中心・範囲も相対パスで解決し、見つからなければ設定を確認するエラーを表示します。口形名が異なるアバターへの自動変換はしません。

未移行の設定は従来どおり使用できます。「Prefabへ保存」で選んだ設定を共有化し、その配置先の旧設定をコンポーネント内の控えに保持します。専用Prefabへ複製すると共通設定も独立します。Prefab Variantは親の共通設定を継承し、そのVariantで保存したときに独立します。

- 機能OFF：通常のAvatar Descriptorの設定を使用。
- 機能ON：個別選択・All・登録した発話パターンを使用。

## 対象の登録

1. 「リップシンク切り替えを使用」をONにします。
2. 上部の「＋ 対象」を押し、名前と顔メッシュを指定します。
3. 顔メッシュはInspectorでHierarchyのSkinned Mesh Rendererを指定します。FBX・Material・ボーンではありません。
4. 共通の口形設定はメッシュを差し替えても保持します。詳細ウィンドウの「口形（15種類）」で確認してください。未指定の口形は従来の検出処理を使います。
5. 「表情の口設定と連動」を対象ごとに設定します。

6. 共通設定を変更したら「Prefabへ保存」を押します。顔メッシュの割り当ては、シーンの保存で保持されます。

対象は1～16個です。既存のFace Trackingメッシュも含めSDKの上限16個以内に収めてください。
同じ顔メッシュを重複登録できません。名前は他の対象・パターン・Allと重複させないでください。
左右ボタンは一覧の順序を変更します。発話の優先順位はありません。

口形は vrc.v_aa、aa、Hukurou_BlendShape.aa などの名前から推測します。形状を解析する機能ではありません。
検出できない場合は各プルダウンで選びます。(None)はその発音では動かしません。全項目が空欄ならビルド時に自動検出します。
少なくとも無音以外の口形が1つ必要です。[Missing]はメッシュに存在しない名前です。
複数対象のシェイプキー名が同じでも使えます。ビルド用コピーに専用の口形を追加し、元FBX・Meshは変更しません。

## 発話パターン

1. 左側の「＋ パターン」で名前を付けます。
2. 中央の顔写真をクリックし、同時に喋らせる対象にチェックを付けます。
3. 全対象OFFなら音声リップシンクを停止するパターンになります。
4. 必要なら複製・上下ボタンで並べ替えます。

個別選択は1つの顔、Allは全対象、発話パターンは任意の組み合わせを動かします。
選択してもメッシュは表示されません。非表示の対象を選んでも、ほかの顔へ自動で切り替わりません。
双子のような用途では2つの顔を登録してAllまたは専用パターンを使います。体の鏡合わせ・追従・反転や表情カーブの自動複製は含みません。

## メニュー

```text
Lip Sync
└─ Speaker
   ├─ Kirishima
   ├─ Hukurou Modoki
   ├─ All
   └─ Twins（追加したパターンの例）
```

右側のプレビューで階層・アイコン・初期選択を確認できます。VRChatの円形メニューそのものではなく階層一覧です。
対象・パターンの「メニューに表示」、右側の「Allを表示」で必要な項目だけを出せます。
非表示のモードも初期選択に指定できます。項目が多い場合はNextでページ分割されます。
VRChatで選択中のトグルを解除して値が0になった場合は、設定した初期発話先へ戻ります。
モード値の上限は255です。

## 顔写真・アイコン

1. 対象を選択するとプレビューが自動表示されます。
2. 撮影中心・位置・角度・ズームを調整すると、その場でプレビューに反映されます。撮影中心にはHeadボーンなどを指定できます。
3. 「撮影範囲」は写真に含める親オブジェクトです。空欄なら身体の顔はアバター、それ以外は顔メッシュを使います。髪や装飾を含める場合はそれらを含む親を指定します。
4. マテリアルなどを外部で変更した場合は「プレビューを更新」を押してください。背景色のAを0にすると透過します。「この写真をアイコンに保存」で確定します。

実際のマテリアルと固定のプレビュー照明で撮影します。元のアバターやマテリアルは変更しません。ワールド内の照明の再現ではありません。
パターンの「選んだ顔からアイコンを生成」で写真を合成します。全対象OFFなら停止マークを生成します。右側ではAllアイコンを生成できます。
写真や組み合わせを変更した場合は合成アイコンを再生成してください。アイコン欄から任意の画像への差し替えも可能です。
画像は `Assets/NSL_FacialExpressionEditor/Icons/LipSync/NSL_名前.png` に保存します。再生成では別名のファイルを作り、以前の画像は上書きしません。既存の画像もGUIDを保持して移動すれば、Prefab・シーン・リップシンク設定からの参照を引き継げます。
設定後はシーン／Prefabを保存してください。

## 表情と口キャンセル

「表情の口設定と連動」がONの対象は、表情ごとのリップシンクON/OFFに従います。OFFの対象は、表情側で止めても音声口パクを継続します。
口キャンセルは、選択されて音声口パクが有効な対象にだけ適用します。
キャンセル用クリップのカーブをメッシュごとに分けるため、未選択の顔の口は戻しません。
複数同時でも、連動ONかつキャンセル用クリップにカーブがある顔それぞれに適用します。
2つ目の顔用のカーブは自動複製しません。既存の口キャンセル設定で必要なメッシュを指定してください。
MMDなどによるアバター全体のリップシンク停止は引き続き有効です。

## 旧版からの移行

設定画面を開いた時、またはビルド時に移行します。
旧Autoの初期選択は、旧設定の初期表示状態から求めた発話先に固定します。利用可能な対象がなければ停止パターンを作ります。
移行後は表示状態を監視しません。「初期選択」を確認し、希望の顔またはパターンを指定してください。
旧Visibilityは生成されなくなります。必要な表示ON/OFFはMAなどで別途設定してください。
旧表示対象は、撮影範囲が空欄だった場合だけ写真の撮影範囲として引き継ぎます。
既に保存したAutoアイコン画像は自動削除しません。

単体版からは画面下部の「旧版からの取り込み」を使えます。取り込みは現在の設定を上書きし、単体版を無効化します。
移行後の単体版LipSyncSwitchは削除できます。MA Bone Proxy・PhysBone・Constraintなど追従や揺れの設定は残してください。

## 環境・検証

SDK 3.10.6以降、MA、NDMFが必要です。専用フェイストラッキング機器は不要です。
検証環境：Unity 2022.3.22f1、SDK 3.10.6、MA 1.18.7。
既存のハードウェア口トラッキングや独自の口制御との共存は個別確認が必要です。
VRChat内の実音声・他人からの見え方・各プラットフォームでの動作は未検証です。

## プレビューのマウス操作

正方形のプレビュー内で右ドラッグすると回転、中ドラッグで平行移動、ホイールでズームできます。数値欄にも反映されます。「構図をリセット」で位置・角度・ズームを初期値に戻せます。
「表情の編集」（作成・編集画面）のプレビューも同じ操作です。編集時の回転・移動・ズームは確認用で、一覧やメニューアイコンの構図を変更しません。撮影用のプレビューカメラ設定は正面固定の高さ・寄り具合スライダーです。リップシンクの写真の構図は対象ごとに保存します。
