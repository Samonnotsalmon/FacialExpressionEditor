# NSL_Facial Expression Editor 操作説明書

アバターの現在の顔をベースに、ジェスチャー表情、固定メニュー、重ねるパーツ、瞬き、口モーフキャンセルを設定するUnityエディタ拡張です。Modular AvatarとNDMFを使い、ビルド用のアバターへ設定を適用します。

この説明書はバージョン0.6.1の操作を扱います。0.5.0とは画面構成が異なります。インストール方法は[README](../README.md)、変更履歴は[CHANGELOG](../CHANGELOG.md)を参照してください。

## 初めて設定する

1. Unityでアバターを配置し、通常時に使いたい顔へシェイプキーを調整します。この状態が「ベース顔」になります。
2. Hierarchyのアバター、またはProjectのアバターPrefabを選択して、`Tools → NotSalmon → NSL_Facial Expression Editor`を開きます。選択していない場合は「新しく始める」からアバターを指定します。
3. 既存の設定が表示されたら、続ける設定を開きます。新規の場合は、表情を編集するメッシュと、必要なオブジェクト・マテリアルの対象を選びます。
4. プレビューカメラを調整し、取り込むアニメーションクリップまたはフォルダを指定します。
5. 元FXの置き換え対象を確認します。作り直す表情制御だけを選び、残したい衣装・ダンス・コンタクトなどのレイヤーは外します。
6. 保存先と設定名を確認して「始める」を押します。シーンのアバターに設定を入れる選択を使うか、生成された`設定名_FEE.prefab`を対象アバターの子に配置します。
7. ジェスチャーや固定メニューへ表情を割り当て、「まばたき・口」を設定します。上部に警告が出たら、内容を修正してからビルドします。

設定用Prefabは表情制御を追加するためのものです。アバター本体のPrefabとは別に生成されます。元のExpressions Menuの整理はModular Avatar側で行ってください。

## 画面の構成

左のクリップライブラリから表情を探し、中央で割り当て、右の詳細プレビューで確認する流れです。

| タブ | 設定すること |
| --- | --- |
| メニュー・ジェスチャー | 表情セット、左右のジェスチャー、固定メニュー、固定時の切り替え演出 |
| パーツ | ほほ染めなど、表情に重ねて使う部分的な変更 |
| まばたき・口 | 共通の瞬き・口キャンセルと、表情ごとの動作ON/OFF |
| モーション連携 | AFKや付属ダンスへ表情制御を譲る条件、ベース顔補正、MMD向け設定 |
| アバター設定 | 編集対象、カメラ、元FXの置き換え、別設定の作成・複製 |

「反応」タブは現在非表示です。コンタクト・PhysBoneの反応を新規作成する操作や、反応ごとのON/OFF追加は、この版の操作対象に含めません。元の反応を使う場合は関連するFXレイヤーを残します。以前に保存した差し替え設定は保持されます。

## 表情を取り込んで割り当てる

### ライブラリとメニューの違い

ライブラリは使用候補のアニメーション一覧です。ライブラリにあるだけでは、ゲーム内の固定メニューには追加されません。

Projectのフォルダをライブラリへドロップすると、その中のクリップを参照できます。サブフォルダはライブラリの絞り込みに使えますが、ゲーム内メニューのフォルダへ自動変換されるわけではありません。

サムネイルを選ぶとプレビューできます。動く表情は再生して確認できます。「未割り当て」は使用先がないこと、「動く表情」は時間によって値が変わることを表し、別の情報です。

### 左右のジェスチャー

1. 「メニュー・ジェスチャー」で表情セットを選びます。
2. ライブラリのクリップを、左手・右手の各ジェスチャー枠へドラッグします。
3. 両手に表情を設定した場合の「優先する手」を選びます。右手を優先したい場合は「右手」にします。
4. 特定の両手の組み合わせだけ別の顔にしたいときは「組み合わせの上書き」を追加します。これは通常の左右割り当てより優先されます。

Neutralは通常ベース顔を使います。動く通常表情などを割り当てたい場合だけ「Neutral も設定する」を開きます。

Fistの「握り具合」をONにすると、握り込みに応じて目元がベース顔からFistに登録した表情へ変わります。口元はFistの完成表情を使います。閉じ方は、そのFist表情を編集して調整してください。OFFなら握ったときに登録表情をそのまま使います。「Fistでは元のカーブを握り込みに使う」は、握り込み用に作られたクリップを使う場合の設定です。

### 固定メニュー

ジェスチャーに割り当てた表情は、ゲーム内の「表情選択」から固定することもできます。固定だけに使いたい表情は、ライブラリから表情メニューやフォルダへドラッグします。

「表情セットを追加」は別のジェスチャー割り当てを作るとき、「フォルダを追加」は固定表情をジャンル別にまとめるときに使います。Addという名前のフォルダは初期状態では作られません。必要なら任意の名前で追加してください。

矢印で並び順を変え、星で初期の表情セットを指定します。メニューの「×」はメニューから外す操作です。表情データ自体の削除とは異なります。同じ表情を複数の場所で使っているときは、詳細の「使っている場所」で確認できます。

## 表情を作成して編集する

### ベース顔から作る

ライブラリの「＋ 表情を作る…」やジェスチャー枠の「＋」から作成します。新しい表情はその設定のベース顔を出発点にします。名前を付けた後、「この表情を編集」から調整します。

編集画面では、シェイプキー、オブジェクトの表示、マテリアルの差し替え、シェーダーのパラメータを扱います。シェーダーのパラメータはマテリアルのインスペクター形式で編集し、変更した数値・色・位置やサイズを自動記録します。元のマテリアルは変更しません。画像の差し替え・シェーダー変更は記録対象外で、同じメッシュの同名パラメータには共通で適用されます。記録された項目とプレビューを確認してください。

元アセットを参照している場合は、編集用のコピーを作って編集します。専用クリップの名前は表情名に合わせて管理します。同名ファイルやファイル名に使えない文字がある場合、保存名は調整されます。

変更は編集対象へ反映されます。「開いたときの状態に戻す」は、その編集画面を開いた時点まで戻す操作です。

### 目と口のクリップを合成する

ジェスチャー枠の「合成…」などから合成画面を開き、目・口などの素材を追加します。各素材で使わないプロパティのチェックを外し、名前を付けて合成します。同じプロパティが複数の素材に含まれる場合は、後の素材が上書きします。

例えば、目だけのクリップと口だけのクリップを合成して、右手のひとつのジェスチャーに完成表情として割り当てられます。動く素材どうしの長さ・ループ設定が異なる場合は、外部のアニメーション編集で揃えてから合成します。

### 動く表情と静止する表情

動くクリップはプレビューで再生して確認します。動きを止めて使いたい表情だけ「指定した時点で静止する」を設定します。通常の数値調整と、クリップの時間方向の動きの編集を区別してください。

### 記録しない値と明示的な0

「値を記録しない」と「0を記録する」は違います。0を記録すると、その項目を0へ動かす命令になります。

新しく作成・複製する表情は、必要なベース顔の値と編集対象を記録します。部分表情やEmptyのクリップへ、無関係なシェイプキーを一律に追加しない方式です。既存の保存済みクリップから不要な値を自動削除する処理ではありません。

ベース顔の笑みを多くの表情に残しつつ、怒り顔だけ口元を変えたい場合は、その表情の編集用クリップを調整します。リップシンク用のシェイプキーはAvatar Descriptorの設定を基に保護されるため、発話用の口形状を通常表情へ記録する用途には使いません。

## パーツを重ねる

「パーツ」から新しいパーツを作り、ほほ染めや小物の表示など、重ねたい項目だけを設定します。パーツは完成した顔全体ではなく、動かす部分だけを記録する用途です。

例えば、通常表情がほほ染めを30にしているとき、ほほ染めパーツがOFFなら表情の30を使い、パーツがONならパーツに登録した値で上書きします。OFFを「必ず0にする」と考えて、不要な0をパーツへ追加する必要はありません。

同時に使いたくないパーツには同じ排他グループを指定します。作成済みのグループを選んで再利用できます。別グループのパーツでも同じ項目を動かすと競合するため、重ねる場合は記録範囲を確認してください。

パーツはドラッグで並べ替えられます。入れたい位置のパーツの上にドロップすると、そのパーツの前に入ります（最後にしたいときは「＋ 新しいパーツ」の枠へドロップ）。ゲーム内のパーツメニューもこの順に並びます。

## まばたきと口を設定する

### 表情ごとのONとOFF

この一覧には、ジェスチャーまたは固定メニューへ割り当てた表情だけを表示します。

| 項目 | ONのときの動作 |
| --- | --- |
| まばたき | その表情でも共通の瞬きを使う |
| 視線 | その表情でも目の追従を使う |
| リップシンク | その表情でも発話に合わせて口を動かす |
| 口キャンセル | 発話中に、指定した口周りの項目をキャンセル用クリップの値へ戻す |

チェックを押したまま同じ列を上下にドラッグすると、複数行をまとめて同じON/OFFにできます。口キャンセルはリップシンクがONで、対象がある場合に設定できます。

リップシンクのメッシュは、このエディタでは指定しません。アバターのInspectorにあるAvatar Descriptorで設定します。

### 共通の瞬き

既存の瞬きがある場合は「まばたきの設定」の「アニメーションクリップ」に指定します。そのクリップをそのまま使用し、「この瞬きをプレビュー」で確認できます。

新しく作る場合は、クリップ欄を空にして「専用の瞬きを新規作成」を押します。目を閉じた状態を編集する画面が開きます。Avatar DescriptorのEye Lookから取得できる場合は目閉じ用シェイプキーを初期値に使い、足りない場合は「＋ シェイプキーを選ぶ」から追加します。

目閉じの値を調整し、「瞬きを再生」で確認します。作成した目閉じからループする瞬きを自動生成します。後からは「目閉じを編集・プレビュー」で変更できます。

クリップ欄が空でも、取得できるEye Look設定などがあれば生成可能な場合があります。上部に未設定警告が出ている場合は、指定または新規作成が必要です。

### 口モーフキャンセル

笑みなどの口の変形が、発話用の口の動きに重なって崩れるときに使います。ONの間ずっと顔を無表情にするものではなく、発話中に対象項目を指定値へ戻します。

既存クリップを使う場合は「口キャンセルの設定」で指定します。使う値はクリップの0秒時点です。例えば笑みを0に戻したいなら、笑みを0に記録したクリップを使います。OFFならこの戻し処理を行わず、表情側の値が残ります。

クリップがない場合の作成手順は次のとおりです。

1. 「専用クリップを新規作成」を押します。
2. 「口変形キャンセル用シェイプキー」を開き、「＋」を押します。
3. 小さい選択ウィンドウで項目を選びます。Ctrlクリックで個別追加、Shiftクリック・Shift＋上下キーで範囲選択できます。
4. 「追加」で確定します。追加した項目は0で登録され、登録一覧で値を調整できます。

ベース顔で変更しているシェイプキーはハイライトされます。戻したい項目を判断する目印にしてください。元のクリップを編集する場合も専用コピーを使います。対象の削除は「−」、全解除は「すべて削除」です。

未指定でも、以前の設定や元アバターからの自動設定が残っていれば使用される場合があります。その場合は画面に案内が表示されます。

### 表情切り替え時の瞬き演出

「メニュー・ジェスチャー」の「固定表情への切り替え（瞬き・演出）」で設定します。

- **共通の瞬きを使う**：「まばたき・口」の目閉じを使います。
- **別の表情を挟む**：切り替えに挟む表情を別途選びます。

現行の演出は固定メニューから表情を選ぶときが対象です。通常のジェスチャー切り替えや動く表情には適用しません。表情詳細から個別の遷移時間・演出も設定できます。

## モーション連携を設定する

### この機能の目的

AFKやアバター付属ダンスの間、エディタが生成する顔の制御を一時停止し、元モーションの顔を見せます。元モーションを新しく再生する機能ではありません。

元モーションが顔を動かすFXレイヤーは残す必要があります。置き換え対象に入れて削除したレイヤーを、連携設定によって復元することはできません。

モーションが終わると、保持していた固定表情・パーツの選択へ戻ります。固定していなければ現在のジェスチャーに戻ります。時間で動くエディタ側の表情について、停止前の再生位置へ戻すことを保証する設定ではありません。

### AFKの表情

基本は元アバターのAFKモーションを使用します。初期の優先条件は`AFKがON`で、通常・固定表情、瞬き、口キャンセル、パーツを停止する構成です。

「ベース顔の変更をAFKの表情に反映する」を使うと、検出した元FXのAFK表情に補正を加えられます。補正で崩れた箇所は「AFKの表情を編集」で調整します。元FXに対象がない場合や顔バリアントがない場合は、その旨を表示します。

条件や停止対象を変える場合は「詳細：AFKの優先条件・停止する機能」を開きます。最後のAFK設定を無効にする場合は、設定名の左のチェックを外してください。

### その他モーションの基本設定

1. 「＋ 元の表情を優先するモーションを追加」を押し、分かる名前を付けます。
2. 「元の表情を使う条件」に、再生中を表すパラメータと値を設定します。ひとつの設定内では、すべての条件が一致した間だけ有効になります。
3. 「その間、停止するエディタの機能」を選びます。
4. モーション中と終了後の両方を確認します。

| 停止する機能 | 停止する目的 |
| --- | --- |
| 通常ジェスチャー・固定表情 | 元モーションの表情が通常・固定表情で上書きされるのを避ける |
| まばたき | モーション中の目の演技に共通瞬きが重なるのを避ける |
| 口変形キャンセル | モーションの口の形をキャンセルしないようにする |
| 重ねるパーツ | モーション中はエディタ側の追加パーツを重ねない |

複数の設定が同時に有効になった場合は、どれかひとつで停止指定された機能を停止します。上から順にひとつだけ選ぶ優先順位ではありません。

Boolはオン・オフ、Intは数値との比較、Floatは大小比較を使います。存在しないパラメータや型に合わない比較は警告になります。

### 汎用的なダンスの設定例

元アバターにInt型の`DanceMode`があり、通常時は0、顔付きダンス中は1を維持し、終了時に0へ戻る構成を例にします。これは説明用の名前です。実際にはアバターにあるパラメータを選びます。

- モーション名：付属ダンス
- 条件：`DanceMode ＝ 1`
- 停止する機能：まず4項目すべてをON
- 参照元クリップへのベース顔補正：まずOFF

元ダンスの顔が出ることを確認してから、残したい機能だけ停止対象から外します。複数のダンスをまとめて`DanceMode ≠ 0`とすると、顔のないモーションまで含む可能性があります。最初は対象を限定してください。

### 詳細の元ステート解析

再生中の条件が分からないときに、「詳細：元ステートの解析・ベース顔補正」を開きます。Animatorの「ステート」は、特定のモーションを再生する状態を指します。

| 項目 | 使い方 |
| --- | --- |
| 元ステートを検索 | ダンスなどのステートを名前で絞り込む |
| 条件の参照元 | 調べたいステートを選ぶ。「手動設定／参照元なし」でも通常の条件設定は可能 |
| 元クリップ | そのステートが再生するアニメーションを確認する |
| 入口 | そのステートへ入るための条件を確認する |
| この入口条件を候補として取り込む | 上の条件一覧を、その入口の条件で置き換える |
| 出口 | ステートから抜ける条件を確認する |
| ステート内の値変更 | Parameter Driverによるパラメータ変更を確認する |

参照元の選択だけでは、そのステートの再生を自動検知しません。入口の条件も、必ずしも再生中の条件ではありません。

例えば、入口が`DanceStartがON`でも、再生直後にParameter DriverがOFFに戻す構成なら、その条件では開始直後にエディタの表情が復帰します。逆に、モーション終了後も条件が成立したままだと、表情を譲り続けます。

取り込んだ条件は、再生中に成立し続け、終了時に外れるかを確認してください。終了時間による遷移、親ステートの条件、他のレイヤーからのパラメータ変更まで、この一覧だけで判定することはできません。必要に応じて元のAnimatorとPlayモードで確認します。

### 詳細のベース顔補正

「参照元クリップにベース顔の補正を反映する」は、元ダンスなどにも自分のベース顔の調整を加えたいときに使います。条件が分かっていて元の顔をそのまま使う場合、詳細の設定は不要です。

補正には対象の元クリップが必要です。ビルド用クリップを加工し、元アセットは変更しません。ただし、条件成立中だけ補正値を重ねる方式ではありません。同じ元クリップをほかのステートでも使っていれば、そちらにも補正が及ぶ場合があります。

同じクリップに対して、複数の有効な設定で補正ON/OFFを混在させると警告になります。AFKの補正対象と重なる場合は、連携条件側の指定が優先されます。

### MMD対応

エディタのMMD欄は「ビルド時にFX全体のWrite Defaultsを一括ONにする」の切り替えです。初期値はONで、元アセットではなくビルド用FXの全ステートを対象にします。

一括ONによって衣装などのギミックが動かなくなった場合は、OFFにして元の各ステートの設定を保持できます。WD OFFが残っていてもビルドは停止しません。MMDへの切り替え・解除で表情の値が残る場合があるため、ギミックとあわせて動作を確認してください。

このチェックだけで、任意の付属ダンスの再生条件が設定されるわけではありません。付属ダンスへ顔を譲る設定は「その他モーションの表情」で行います。

## アバター設定と複製

### 元FXの置き換え

「置き換える元FXレイヤー」で選んだレイヤーは、新しい表情制御の生成時に取り除きます。必要な衣装・付属モーション・反応のレイヤーを誤って含めないでください。耳や尻尾が動かなくなった場合も、まずこの選択と元FXのパラメータ依存関係を確認します。

「残す元FXの顔制御（詳細）」では、検出した顔制御レイヤーを「そのまま」「顔のカーブだけ取り除く」「使わない」から選べます。顔以外のギミックを含むレイヤーで、レイヤー全体を消すべきか判断するときに使います。顔カーブの除去範囲は設定された編集対象に依存するため、必要な動作が残ることを確認してください。

### ベース顔を変えた場合

登録済みの顔をシーン上で変更した場合は、変更したベース顔で新しい設定を作成します。「表示を更新」は見た目を撮り直す操作であり、保存済みのベース顔を読み直してすべての表情へ適用する操作ではありません。

「アバター設定」の「新規作成…」は空の設定から始める場合、「今の設定を複製…」は割り当てと編集済みクリップを引き継ぐ場合に使います。「今の設定を複製…」では保存ダイアログで場所と名前を決め、現在の設定コンポーネントが参照するデータを新しいものへ切り替えます。現在のアバターからベース顔を読み直します。

設定用Prefabも別にしたい場合は、設定用PrefabのInspectorで「複製してこのアバター専用にする」を押します。名前を指定し、表示された保存先を確認して「複製して適用」を押します。元設定フォルダの隣へ独立したフォルダを作り、対象アバターの設定用Prefabを新しいものへ置き換えます。同名がある場合は番号が付きます。こちらも現在のベース顔を読み直し、以後の専用クリップの編集は複製元に影響しません。

例えば、同じ表情割り当てを使いながら別のメッシュでリップシンクさせたい場合は、専用設定へ複製し、Avatar Descriptorのリップシンク設定と表情ごとの口キャンセルを調整します。異なるメッシュ名・シェイプキー名への任意のアニメーションの自動変換を保証するものではありません。

## プレビューとメニュー画像

髪や服のGameObject、またはRendererの表示を切り替えて「表示を更新」を押すと、編集用プレビューやサムネイルを更新できます。Hierarchyの目アイコンによるSceneビューだけの非表示は対象外です。

カメラの高さ・寄り具合は初期設定または「アバター設定」の「プレビューカメラ」で調整します。一覧・詳細・メニューアイコンの構図に使用します。

ビルド時のメニュー画像は、ビルド対象アバターの外見に表情を適用して生成します。編集用に前髪を隠していると、その状態も画像に含まれるため、必要ならビルド前に戻してください。同じ外見の画像があればキャッシュを再利用します。

撮影はModular Avatarの処理前です。ビルド中に行われる最終加工や、ゲーム内の衣装変更後の外見を自動撮影するものではありません。Android・iOS向けの画像形式はビルド先に合わせて設定します。

## ゲーム内の操作

- **表情選択**：ジェスチャーに割り当てた表情や、固定専用の表情を選びます。
- **Base**：登録したベース顔を固定します。
- **固定解除**：固定を解除し、現在のジェスチャーへ戻します。パーツの選択は保持します。
- **パーツ**：追加パーツを切り替えます。排他グループでは同時選択を制限します。先頭の「すべてOFF」を押すと、ONにしているパーツをまとめてOFFにします。
- **まばたきOFF**：共通の瞬きを止めます。
- **ダンスギミック有効（MMD対応）**：MMD向けの連携を有効にします。付属ダンスの個別条件設定とは別の操作です。

「まばたきOFF」と「ダンスギミック有効（MMD対応）」の選択状態は保存しません。

## 警告と困ったときの対処

### ビルド前の警告

警告に移動ボタンがある場合は、そのボタンから該当する設定を開けます。

| 警告の内容 | 確認すること |
| --- | --- |
| 瞬きが未設定、対象が見つからない | 「まばたき・口」で既存クリップを指定するか、専用の瞬きを作成し、有効なシェイプキーを登録する |
| モーションの条件がない | 条件を追加する。使わない設定なら左のチェックで無効にする |
| パラメータがない、比較の型が不正 | 実在するパラメータを選び、Bool・Int・Floatに合う比較へ変更する |
| 参照元レイヤーがない、置換対象と重なる | 参照元を選び直すか、必要な元レイヤーを残す。自動置換する瞬き・口制御レイヤーも連携元には使わない |
| 補正対象の元クリップがない | 詳細で参照元を選ぶか、ベース顔補正をOFFにする |
| 同じクリップの補正指定が食い違う | 有効な連携設定どうしで補正ON/OFFを揃える |
| 固定できる表情が上限を超える | ジェスチャー・固定メニューで使う異なる表情を、Baseを除いて254個以内にする |
| 一括ONが無効でWD OFFが残っている | ビルドは可能。ギミックとMMD中の表情の切り替え・解除を確認する |
| 以前の反応設定が参照切れ | 「設定データを選択」から旧差し替えデータを確認する。反応タブは非表示のため、通常画面からの再設定はできない |

これらはエディタが把握できる設定の検査です。SDKや他の拡張が行う最終ビルドの検証すべてを置き換えるものではありません。

### 表情や口が想定どおりに動かない

| 症状 | 確認すること |
| --- | --- |
| ダンス中の顔が動かない | 顔を動かす元FXを残しているか、連携条件が再生中ずっと成立しているか、必要な機能を停止しているか |
| ダンス終了後も表情が戻らない | 条件に使うパラメータが終了時に戻っているか、別の連携設定が成立したままではないか |
| リップシンクが動かない | Avatar Descriptorのメッシュ・Viseme指定、表情のリップシンクON/OFF、残した元FXが同じ口を制御していないか |
| 口キャンセルで笑みが消える | キャンセル対象と0秒時点の値を確認する。残したい笑みなら対象から外すか、戻す値を調整する |
| パーツOFFでもほほ染めがある | 元の表情にもほほ染めが含まれていれば正常。OFF時は表情の値を使う |
| パーツOFFなのに意図しない値が残る | 表情クリップ、パーツの記録範囲、元FXの同じプロパティの制御を確認する |
| 前髪を隠しても画像が変わらない | Sceneビュー専用の非表示ではなくGameObject／Rendererを切り替え、「表示を更新」を押す |
| 表情の一部しか変えないのに他の部位が動く | クリップに不要な値や明示的な0が入っていないか確認する |

プレビューは見た目の確認に使い、パラメータ条件、元FXとの共存、発話中の制御はビルド・Playモード・実機でも確認してください。
