# 表情・ジェスチャー設定エディタ拡張 仕様

## 目的
VRChatアバターの表情改変・ジェスチャー設定を、自分の改変ワークフローに合う形で行えるUnityエディタ拡張を作る。FaceEmoを置き換える独自システムとする。

## 背景・FaceEmoで困っている点
- 同じUnityプロジェクトに、シーンごとに標準顔（ジト目・ツリ目・タレ目など）を変えたバリアントのアバターが並ぶ。
- 最初の顔はバリアントごとに違うが、表情の設定は共通にしたい。元アバターのアニメーションを、自分がわかりやすい並びにしたものを使う。
- FaceEmoでは保存構造が思い通りにならず、バリアント間で流用・変更しにくい。
- 元アバターにAFK表情があると、その部分だけベース顔に合わせた編集ができず、表情が破綻することがあった。

## よくある改変の流れ（2026-10-06に聞き取り）
1. 元のアバターのベース顔を、少しだけ自分好みにいじる（目の大きさなど）
2. 作者さんのアニメーションを使って、自分の使いやすい割り当てに変える。固定メニューにも、ほぼ全部の表情を並べる
3. その後、全然違う顔にすることもある。元の表情も使うが、新しく作ることも多い
- 表情セットやパーツが最初から入っていないアバターもあり、表情を最初から作って割り当てることもある

## FaceEmoから残したい点
- ジェスチャーと表情を対応づけて設定できること
- アニメーションのプレビュー

## 決定事項
### 全体
| 項目 | 決定内容 |
|---|---|
| スコープ | FaceEmoを置き換える |
| 利用者 | 自分専用。ただし他ツールと併用するため、依存関係と競合に配慮する |
| 環境 | VRChat推奨のUnity / VCC / Modular Avatar（非破壊処理に使う） |
| フェイストラッキング | 当面は考慮しない |
| メッシュとシェイプキーの名前 | バリアント間で同じ。クリップのパスを置き換える機能は不要 |

### 表情
| 項目 | 決定内容 |
|---|---|
| 表情データ | 顔全体を1クリップで持つ |
| 対象プロパティ | シェイプキー、マテリアルの差し替え、オブジェクトのオン・オフ、シェーダーのパラメータ（lilToonの2ndメインカラーの不透明度などで頬染めするアバターがあるため） |
| 設定の単位 | フラグや遷移時間などの設定は、表情（クリップ）単位で持つ。同じ表情はどこに割り当てても同じ設定になる。別の設定にしたいときは表情を複製する |
| まばたき・リップシンク | FaceEmoと同様に、表情ごとにオフにできる。口モーフキャンセラーも付ける |
| まばたきの止め方（2026-10-06、ユーザーの判断） | FaceEmoの「まばたきを置き換える」と同じ方式。VRChatのまばたき（Eyelids の Blink）をビルド時に外し、同じシェイプキーを動かすまばたきのアニメーションに置き換える。表情ごとに「まばたき」と「視線（目の動き）」を別々にオン・オフできる（まばたきを止めても視線は動かせる）。置き換えをオフにした場合や、まばたきのシェイプキーが無いアバターでは、まばたきを止める表情で視線も止まる |
| まばたきのアニメーション（2026-10-06、ユーザーの判断） | 標準はFaceEmoと同じく元アバターのもの。元FXにまばたきのアニメーション（名前に blink / まばたき / 瞬き を含むレイヤーかクリップで、シェイプキーだけを動かすもの）があればそのまま使い、そのレイヤーは取り除く。無ければアバターの設定（Eye Look の Eyelids）のまばたきのシェイプキーを、10秒に3回のまばたきのカーブで動かす。「自分で編集する」で、シェイプキーの追加・削除と閉じたときの値を変えられる（オフに戻すと元アバターのものを使う。編集した内容は残る） |
| 元FXからの取り込み（まばたき・リップシンク） | 元FXのジェスチャーのステートで目（Eyes）をアニメーションにしていた表情は「まばたきオフ」、口（Mouth）をアニメーションにしていた表情は「リップシンクオフ」として取り込む。ボタンを押さなくても、取り込み時と、この機能より前に作った表情データを表情エディタで開いたとき（一度だけ）に自動で取り込む。視線はオンのまま（しなのは全表情で目をアニメーションにしていたので、取り込むと全表情がまばたきオフになる） |
| 口モーフキャンセラー（2026-10-06） | 話している間（Viseme が0以外）、指定した口のシェイプキーをアバターの今の値（ベース顔）に戻す。表情ごとに止められる（リップシンクを止めた表情では働かない）。標準は元アバターのもの：元FXの口モーフキャンセラー（Viseme を条件にしてシェイプキーだけを動かすレイヤー。しなのの `Rip_OFF`）のシェイプキーをボタンを押さなくても使い、そのレイヤーを同じ位置で置き換える。「自分で編集する」で、シェイプキーの追加・削除ができる |
| Fistトリガー（2026-10-06に変更、ユーザーの判断） | 使う（主な用途は、右手Fistの握り具合で目を閉じること）。別の「トリガー時のクリップ」は持たず、Fistのマスに割り当てた表情そのものへ、握り具合0のベース顔（無表情）から変わる。クリップ自体が握り具合で動くように作られた表情（しなのの目閉じなど）は、そのクリップの動きをそのまま使う。設定と確認は、表情セットの表のFistのマスだけで行い、表情の詳細やプレビューには含めない |
| Fistの握り具合のオン・オフ（2026-10-06） | 表情セットごとに、左右それぞれオン・オフできる（表の左右のFistのマスで切り替える）。初期値は左手オフ・右手オン（左手は押し込みなしの表情にすることが多いため）。オフの手は、握るとそのまま表情が出る |
| 遷移時間 | 全体で1つの値を持ち、必要な表情だけ個別に設定できる |
| 表情が終わったとき | 表情で変えたプロパティ（頬染めのシェーダーパラメータなども含む）は、元の状態に戻す |

### パーツ（2026-10-06追加）
| 項目 | 決定内容 |
|---|---|
| パーツとは | 汗・涙・頬染めなど。ゲーム中にメニューからオンにすると、ジェスチャーで変わる表情の上に重なって出続ける（しなのの元の構成と同じ使い方） |
| 同時に出せる数 | 複数同時にオンにできる。同時に出てほしくないもの（目のパーツ同士など）は「排他グループ」にまとめ、グループ内では1つだけ出る |
| 動かすプロパティ | パーツとして追加したいものだけを動かす。取り込み時は0以外の値のプロパティだけを選び、画面でプロパティごとにチェックを付け外しできる（しなのの頬染めは `eye_happy` も含むので、必要なら外す） |
| 元のパーツ用レイヤーとメニュー | 取り込んだら、ビルド時に元のレイヤー（しなのの `Facial_parts`）とメニュー項目を外し、このツールのパーツメニューに置き換える |

### 表情セット（ジェスチャーの組）（2026-10-06追加）
| 項目 | 決定内容 |
|---|---|
| 取り込み | アバターに既存の表情セット（しなのの `F_Set` の3セットなど）は、すべて表情セットとして取り込む |
| 表情メニュー（2026-10-06、FaceEmoと同じ構成） | ゲーム内のメニューは「モード選択」と「表情選択」に分かれる（FaceEmoのソースで確認）。モード選択：表情セットが2つ以上あるとき、表情セットをエディタで作った木構造のとおりに並べる（`FEE/Mode`）。★の表情セットが、何も選んでいないときの状態（値0）。固定だけの表情はモード選択には並べない（2026-10-06、ユーザーの判断。表情選択と重複するため）。表情選択：エディタで作った木構造のとおりに、表情セットはフォルダにしてその**ジェスチャーに割り当てた表情**を、固定だけの表情はそのまま、**自動で並べる**。表情セットのフォルダの中は、優先する手の Fist → HandOpen → … → ThumbsUp → Neutral、反対の手も同じ順、最後に組み合わせ（2026-10-07、ユーザーの判断）。選ぶと固定される（`FEE/Emote`）。解除すると、今選んでいるモードに戻る。モードと表情選択は**後から選んだほうが表示される**（FaceEmoと同じ。表情選択で固定中にモードを選び直すと、表情選択は解除される）。どちらもワールドを移動したら戻す（保存しない） |
| ジェスチャーと固定の関係 | ジェスチャーに割り当てた表情は、すべて表情選択で固定できる（ジェスチャーだけで使う表情は無い前提）。そのため、ジェスチャーとは別に「固定」へ同じ表情を登録する必要は無い。エディタの表示も、ジェスチャーへの割り当てだけを使用箇所として見せる |
| 固定だけの表情 | ジェスチャーに割り当てない表情は、表情メニューに「固定だけ」の項目として置く（表情選択に並ぶ）。表のようなものには割り当てず、並び順だけを決める。ライブラリにあってどこにも無い表情を「その他」フォルダにまとめて追加できる |
| 重複 | 同じ表情が2か所以上に割り当てられることは基本的に無い前提で、重複は禁止せず目印で見せる（ジェスチャーの枠と使用箇所に「重複」、ジェスチャーに割り当て済みの表情を固定だけの項目に追加したら通知と目印）。左右で同じジェスチャーに同じ表情は「両手」として1か所に数える |
| 取り込み時のメニュー | 表情セットだけをメニューに並べる（その表情は表情選択に自動で並ぶ） |
| 元の切り替えメニュー | 元のアバターの切り替えメニュー項目は外す |
| メニューのアイコン（2026-10-06） | 表情選択の表情には、その表情のサムネイルを付ける。モード選択の表情セットには無表情（ベース顔）のサムネイルを付ける（128px、DXT5に圧縮、背景は不透明）。表情エディタのサムネイルと同じ Library/ のキャッシュを使う。プレイモードへの切り替え中はUnityのプレビュー描画が失敗するので、プレイボタンを押した直後（まだ編集モードのうち）に足りないものを描いておく。アイコンの用意に失敗してもビルドは止めない |
| 固定した表情の切り替え（2026-10-06） | 標準は通常の遷移（遷移時間0なら一瞬）。「切り替え演出」で、間に別の表情（瞬き・目閉じなど）を挟める（挟む表情、挟む時間、戻る時間）。表情データ全体の標準と、表情ごとの「標準／なし／個別」の設定を持つ。固定用のクリップの頭に挟む表情を入れて実現するので、ステートや遷移は増えない |

### ベース顔とバリアント
| 項目 | 決定内容 |
|---|---|
| ベース顔の作り方 | シーン上でSkinnedMeshRendererのシェイプキー値を直接変えている。元Prefabとの差分（Prefab Override）から自動検出する |
| 検出する範囲 | 表情データのクリップが動かすシェイプキーのうち、元Prefabと値が違うもの。体型など表情で動かないシェイプキーの違いは、無効の状態で一覧に出し、手動で有効にできる |
| ベース顔と表情の関係（2026-10-07変更、ユーザーの判断） | ベース顔は**すべての表情に適用**する（表情ごとの残す／外すや、顔ごとの標準の切り替えは持たない。分かりにくかったため）。表情ごとに変えたいところ（ウインクで閉じている目はジト目にしない、など）は、表情の編集ウィンドウの青い行（ベース顔とその左右別のシェイプキー）で、**この顔のこの表情だけの値**として持つ（0 にすればその表情ではベース顔が無くなる）。共有のクリップは変えない |
| ベース顔の適用 | 表情クリップの値に「バリアントの値 − 元Prefabの値」を足し、0〜100に収める（例：ジト目+60、怒り顔30 → 90）。表情クリップが動かしていなければバリアントの値。その後に、この表情だけの値で上書きする |
| 顔バリアント（2026-10-06） | ベース顔と表情の差し替えを持つ**アセット**。同じ顔の別アバター（服違いなど、別シーンにあるもの）は、同じ顔バリアントを指定して共有する |
| バリアント名 | 初期値は、最初にその顔で顔バリアントを作成したアバターのオブジェクト名 |
| バリアントごとの差し替え | バリアント側で表情を複製して編集し、そのバリアント専用のクリップとして持つ（AFK表情も対象）。差し替えたクリップはそのバリアント用に作ったものなので、ビルド時にベース顔の差分は足さずにそのまま使う |
| 複製時のベース顔 | 複製したクリップには、その顔で見えるとおりにベース顔を反映しておく（差分を書き込む。この表情だけの値は書き込まず、上から適用し続ける）。反映済みの印を持ち、二重に足さない |
| 新しい表情 | 「今の顔から」「既存の表情をコピー」「空から」の3通りで作れる。保存先は `<表情データのフォルダ>/Expressions/` |
| 全然違う顔 | 表情データを複製してそのアバター専用にする。割り当てや固定メニューを引き継いだまま、新しい表情を足したり割り当てを変えたりしても元には影響しない（表情のIDは同じなので、顔バリアントの差し替えもそのまま使える） |
| バリアント専用クリップの保存場所 | `<表情データのフォルダ>/Variants/<バリアント名>/`（顔バリアントのアセットも同じ場所） |
| 用語（2026-10-06） | 素体ごとの共有アセットはUI上「表情データ」と呼ぶ。「表情セット」はジェスチャーの組（しなのの `F_Set` の各セットなど）を指す |

### 取り込みと割り当て
| 項目 | 決定内容 |
|---|---|
| 表情の取り込み元 | 元FXのハンドジェスチャーレイヤー（販売者が用意したもの）と、そのFXが参照しているクリップのフォルダ（使われていない同梱表情も拾うため）。任意のフォルダを後から追加で登録できる（販売の表情セット用） |
| 元FXに何も無いアバター | しなのと違い、表情セットやパーツが無い（FXも無い）アバターもある。空の表情データを作り、表情セット・表情・パーツをツールで後から追加できる。置き換える元レイヤーが無ければ、生成レイヤーはFXの末尾に追加する |
| ジェスチャー割り当て | 左手8種・右手8種と優先する手を基本にする。特定の組み合わせ（両手ピースなど）だけ、マス単位で上書きできる |
| 表情メニュー | 表情メニューから表情を固定する機能が基本（必須）。複数の表情セットをメニューで切り替えることもできる（上の「表情メニュー」を参照） |
| AFK表情 | 元アバターにAFK表情があれば認識して取り込み、ベース顔のルールとバリアントの差し替えを適用できるようにする |
| コンタクト・PhysBone | アバターに元からあるものだけを使い、新規追加はしない。ジェスチャーの表情より優先する。表示するのはパラメータの条件を満たしている間だけで、持続時間は元アバターの設定に従う |
| 複数のコンタクト・PhysBoneが同時に反応したとき | 一覧で上にあるものを優先する |
| 表情の優先順位 | AFK ＞ 表情選択（固定） ＞ コンタクト・PhysBone ＞ 選んでいる表情セットのジェスチャー（マス単位の上書き ＞ 優先する手 ＞ 反対の手） ＞ 無表情（ベース顔） |
| ジェスチャー名の表記（2026-10-06） | 英語（Neutral, Fist, HandOpen, FingerPoint, Victory, RockNRoll, HandGun, ThumbsUp） |
| Neutralの扱い（2026-10-06） | Neutralでは無表情（ベース顔）になるので、エディタのジェスチャーの表には通常出さない。動く通常表情を使う場合などに「Neutral も設定する」で表示して割り当てる（割り当て済みなら常に表示） |
| 元FXの表情以外の演出 | AFKレイヤーなどは、ビルド時に顔メッシュのカーブだけを取り除き、パーティクルなどの演出は残す（加工するのはコピーで、元アセットは変更しない） |

## 画面構成
### ウィンドウ
- **ジェスチャー設定ウィンドウ**（メイン）と**表情編集ウィンドウ**を分ける。

### ジェスチャー設定ウィンドウ（2026-10-06実装：メニュー「Tools/Samon/表情エディタ」、またはアバターのインスペクタのボタン）
- 実装した構成：上にアバターの選択、左にクリップライブラリ、中央にタブ（メニュー・ジェスチャー／パーツ）、右にプレビューと選んだ表情の設定。
- 「メニュー・ジェスチャー」タブ（2026-10-06、FaceEmoと同じく1つにまとめた）：表情メニュー（モード）の木構造（ドラッグで並べ替え・フォルダへ移動、ライブラリからドロップで固定だけの表情を追加、★で既定の表情セット）。メニューの表情セットを選ぶと、その下にジェスチャーの表が出る。表情セットの行には、表情選択に並ぶ件数を出す。
- 右の設定では、名前・遷移時間・この表情の間の動き（まばたき・視線・リップシンク・口モーフキャンセラー）・顔バリアントでのベース顔の扱い（シェイプキーごとのチェック）・差し替え（複製／共有に戻す／ベース顔を反映）・使っている場所（その場で「外す」ボタンで割り当てを外せる）を扱う。表情のプレビューは、クリップを最後まで再生した形（ゲーム内で固定したときと同じ）。
- Fistの握り具合（2026-10-06）：表情セットの表の左右のFistのマスに「握り具合」のオン・オフを出す。オンのマスを選ぶと、右のプレビューに握り具合のスライダーが出る（0でベース顔、1で表情）。組み合わせの上書きでも、優先する手がFistで握り具合がオンなら同じ。
- 「まばたき・口」タブ（2026-10-06）：まばたきの置き換えのオン・オフと、使うまばたき（元アバターのもの／自分で編集）、表情ごとのまばたき・視線・リップシンク・口モーフキャンセラーの一覧（サムネイル付き。まとめて切り替えられる。元FXの設定に戻すボタン）、口モーフキャンセラーで戻すシェイプキー（元アバターのもの／自分で編集：検索して追加・外す）。
- 上部で、編集するアバター（バリアント）と表情セットを選ぶ。
- 顔のアップをウィンドウ内でプレビューする。
- クリップライブラリ（登録したフォルダ）にあるすべての表情を、サムネイルで一覧表示する。
- ライブラリからドラッグ＆ドロップで割り当てられる。割り当て先は、ジェスチャーの表、組み合わせの上書きマス、メニュー固定、コンタクト、AFK。
- どこにも割り当てていないクリップを「未割り当て」として表示し、絞り込める。割り当て済みのものには使用箇所を表示する。
- タブ：ジェスチャー / メニュー固定 / コンタクト / 元FXレイヤー

### 表情編集ウィンドウ（2026-10-07実装：表情エディタの右の「この表情を編集」、またはインスペクタで新しい表情を作ったとき）
- 構成：左に顔のプレビュー（寄る・向きのスライダー）と、何を編集しているかの表示と「開いたときの状態に戻す」、右にタブ（シェイプキー／オブジェクト・マテリアル／シェーダーのパラメータ）。上で編集する表情を切り替えられる。
- 編集はすぐクリップに書き込む（Ctrl+Z で戻せる。2026-10-07、ユーザーの判断）。表情エディタのプレビューとサムネイルもすぐ描き直す。
- 作者のクリップ（表情データのフォルダの Expressions/ の外にあるもの）は、最初に編集したときに Expressions/ へ複製し、表情をその複製に付け替えてから編集する（元のファイルは変えない。2026-10-07、ユーザーの判断）。元のクリップは表情の「複製元」（`originalClip`）に覚えておき、元FXの取り込み・ライブラリの使用状況・ドロップでの割り当てでは同じ表情として扱う。
- 顔バリアントの差し替えがある表情は、そのバリアント専用のクリップを編集する（そのことを表示する）。未編集の差し替えを編集するときは、先にベース顔を書き込んでから編集する。
- シェイプキー：メッシュを選び、検索・変更したものだけの表示ができる。数百あっても重くならないよう、見えている行だけを描く。「変更した」は、共有の表情なら元Prefabの顔、差し替えならこの顔（シーン上の値）と違うもの。×でクリップから外す（この表情で動かさない）。時間で動くカーブ（握り具合で動く目閉じなど）は、最後のキーの値だけを変える。
- シェイプキーの検索
- 変更したものだけを表示
- グループ化：区切り用のシェイプキー（`===目===` など）があればそれで分け、なければ名前の頭の文字で分ける
- 左右対称の同時編集はしない（2026-10-07、ユーザーの判断）。代わりに、顔バリアントのアバターでは、ベース顔で変えているシェイプキーと、その左右別のシェイプキー（`eye_zitome1` なら `eye_zitome1_L` / `_R`）を先頭の「ベース顔」にまとめ、色を変えて出す（ウインクで開いている目だけジト目にする、のような顔ごとの調整のため。2026-10-07、ユーザーの要望）。ほかのグループでも、ベース顔のシェイプキーは同じ色で出す。
  - 青い行は、共有の表情でも差し替えでも、この顔のこの表情だけの値を編集する（2026-10-07変更）。出す値はプレビューで見える値。×でこの表情だけの値をやめる（ベース顔を適用した値に戻る）。「開いたときの状態に戻す」はこの値も戻す
- マテリアルの差し替え（メッシュとスロットごと）、オブジェクトのオン・オフ（ヒエラルキーからドロップで追加。今と逆の状態で追加する）
- シェーダーのパラメータの指定（頬染めなど）：メッシュを選んでパラメータを名前か説明で検索して追加（値は今のマテリアルの値から）。色は成分ごと（`material._Color2nd.a` など）にクリップへ書き込み、4成分そろっていればカラーで、1成分なら数値（色は0〜1、Rangeはその範囲のスライダー）で編集する
- バリアント専用の表情を編集しているときは、そのことを表示する

## データモデル
### 表情データ（共有アセット、素体ごとに1つ。コード上は `ExpressionSet`）
- **クリップライブラリ**：登録したフォルダの一覧。開くたびに再スキャンする
- **表情**
  - クリップの参照（作者のクリップを編集のために複製したときは、元のクリップも「複製元」として持つ）
  - フラグ：まばたき / 視線 / リップシンク / 口モーフキャンセラー
  - 遷移時間（未設定なら全体の値を使う）
- **表情メニュー**：項目（フォルダ／表情セット／固定だけの表情）の一覧。表情セットのジェスチャーに割り当てた表情は、ここに置かなくても表情選択に自動で並ぶ。親フォルダとリストの順で木構造を表す。コード上は `MenuNode`。既定の表情セット（`defaultModeId`）、固定の表情の切り替え演出、メニューのアイコンの設定も持つ
- **表情セット**（複数。コード上は `GestureSet`）
  - 名前
  - Fistの握り具合を左右それぞれ使うかどうか
  - 左手の表（8種）と右手の表（8種）
  - 優先する手
  - 組み合わせ単位の上書き（左手 × 右手 → 表情）
- **パーツ**：名前、クリップ、排他グループ、動かすプロパティ
- **まばたきの置き換え**（オン・オフ）、**まばたき**と**口モーフキャンセラー**それぞれの「自分で編集する」とシェイプキーの一覧（オフなら元アバターのものを使う）
- **置き換える元FXレイヤー**：ジェスチャー用とパーツ用（まばたきと口モーフキャンセラーのレイヤーは、ビルドのたびに元FXから見つける）
- **AFK表情**：元FXから取り込んだもの、または自分で指定したもの
- **コンタクト・PhysBoneトリガー**：既存パラメータの条件 → 表情（並び順＝優先度）
- **元FXレイヤーの処理**：レイヤーごとに「無効化する」か「顔のカーブだけ取り除く」か

### 表情設定（シーン内アバターに付けるコンポーネント。コード上は `FacialExpressionAvatar`）
- 使う表情データと顔バリアントの参照

### 顔バリアント（アセット。コード上は `FaceVariant`）
- **ベース顔**：シェイプキーごとに、元Prefabの値、検出時のバリアントの値、有効・無効。元Prefabとの差分から自動検出し、手動で調整もできる。すべての表情に適用する
- **この顔のこの表情だけの値**：表情 → シェイプキーと値（ベース顔とその左右別のシェイプキー）。ベース顔を適用した後に上書きする
- **表情の差し替え**：表情 → このバリアント専用のクリップ（複製時の共有クリップのハッシュと、ベース顔を反映済みかの印も持つ）。中身が共有の表情と同じ（複製したまま編集していない）差し替えは、差し替えていないものとして扱い、ベース顔の設定がそのまま効く（2026-10-07。古い標準「外す」のまま複製した差し替えで、ベース顔が出なくなっていたため）。編集した差し替えはそのまま使い、表情ごとのベース顔のチェックは効かない（画面でもそう表示する）
- 別のアバターで使うとき、そのアバターのベース顔が検出時と違えば警告する

### ビルド時（NDMF / Modular Avatar）
- FXレイヤー、Expression Parameters、Expressions Menuを生成し、MAでマージする
- 元FXの表情レイヤーとAFKレイヤーを処理する（無効化する、または顔のカーブだけ取り除く）
- シーン上のアバターや元のアセットは変更しない

## 技術メモ
- 非破壊化：シーン上のアバターやアセットは直接変更せず、ビルド時（NDMF/MA）に生成・マージする。
- マテリアルの差し替え：AnimationClipのObjectReferenceカーブ（`m_Materials.Array.data[n]`）で扱う。
- シェーダーのパラメータ：Rendererの `material.<プロパティ名>` カーブで扱う（例：lilToonの `material._Color2nd.a`）。lilToonの最適化やAvatar Optimizerなど、ビルド時にマテリアルやメッシュを加工するツールと併用したときの挙動を確認する。
- 元に戻す処理：表情で動かすプロパティをすべて、無表情ステートにも現在値で書き込む。こうするとWrite Defaultsがオンでもオフでも元に戻る。WDは元アバターのFXに合わせる。
- 元FXの取り込み：遷移条件にGestureLeft / GestureRightを使っているレイヤーを、ハンドジェスチャーレイヤーとして検出する。各ステートのクリップを、対応するジェスチャーと一緒に取り込む。
- AFKの検出：元FXで `AFK` パラメータを遷移条件に使っているステートやレイヤーを探す。
- 既存のコンタクトとPhysBoneは、パラメータを読むだけにする：VRC Contact Receiverの受信パラメータと、VRC PhysBoneの `{名前}_IsGrabbed` / `_Angle` / `_Stretch` / `_IsPosed` など。コンポーネント自体は変更しない。
- バリアントの差し替えは「複製」方式にする。複製した後で共有側の元クリップを直しても、複製側には反映されない。そのため、共有側が更新されたことを示す表示があるとよい。
- サムネイル：プレビュー用のカメラで顔を撮影し、キャッシュする。キャッシュはプロジェクトの `Library/FacialExpressionEditor/Thumbnails/` に置き、`Assets/` を散らかさない。キーには、クリップや顔バリアントの内容（中身から作るハッシュ。保存前の変更でも変わり、保存やプレイモードに入るときのリロードでは変わらない）とアバターの今の顔（シェイプキーの値）を含め、変わったら描き直す。
- プレビューの仕組み：アバターの複製をプレビュー専用のシーン（PreviewRenderUtility）に置き、シーン上のアバターには触らない。複製は非アクティブな親の下に作り、動き出す前に描画に要らないコンポーネント（スクリプト、Animator、コライダーなど）をすべて取り除く（PhysBoneやMAのスクリプトが残っていると、プレイモードで 'ShouldRunBehaviour()' のアサーションが大量に出るため）。クリップのカーブを直接書き込む（シェイプキー、オブジェクトのオン・オフ、Rendererの有効・無効、マテリアルの差し替え、シェーダーのパラメータ）。プレビュー用のシーンではシェイプキーの変更が描画に反映されないため、描画の直前に BakeMesh した形を MeshRenderer で描く。
- プレビューのクリップは、ビルドと同じベース顔の処理（`BaseFaceProcessor`）を通すので、ビルド後の見た目と一致する。
- 参考：FaceEmoのメニュー（2026-10-06にソースを確認）。ルートに「モード選択」（モードの木構造をIntトグルで）、「表情選択」（モードの木構造と同じフォルダ構成で、各モードの表情を別のIntトグルで。固定だけのモードの表情も並ぶ。選ぶと固定）、「設定」が並ぶ。今の表情は1つのIntで、モードを選び直すとモードの表情で上書きされるので、後から選んだほうが勝つ。
- 参考：FaceEmoのプレビュー（2026-10-06にソースを確認）。サムネイルは、アバターの複製をプレビュー用のシーンに置き、`AnimationMode.SampleAnimationClip` で表情を適用してカメラで撮影している。大きいプレビューは、SceneViewを継承した専用ウィンドウに、隠した複製を `AnimationMode` で表情を付けて表示している。`AnimationMode` はエディタ全体の「アニメーションモード」を使う（その間、インスペクタで動かした値が赤く表示されるなど）。このツールでは、エディタの状態に影響しないよう `AnimationMode` は使わず、値の直接書き込みと `BakeMesh` で描く。

### 負荷を抑えるための方針（2026-10-06）
- **前提**：負荷は少なくしたいが、人が見て分かりにくい仕組みにはしない。ブレンドツリーへの数値の詰め込みのような、追いにくい最適化は使わない
- **生成する表情レイヤーの構成**：ルートに「Neutral」、サブステートマシン「Gesture」と「Fixed」に表情のステートを置く。遷移には「Mode 1 Set_1: Right HandOpen -> Smile_1」「Emote 2: Smile_1」のような名前を付ける。
- **生成するFXとアニメーションの名前**（2026-10-07、ユーザーの判断）：レイヤー・ステート・遷移・クリップの名前に、日本語などの2バイト文字を使わない。表情やパーツの名前に英数字以外が含まれるときは、データ上の番号を使った名前（`Expression3`、`Part2` など。英数字の部分があれば後ろに付ける）にする。Expressionsメニューは日本語のままでよい。固定用のステートは表情ごとに1つ（ステートが増えても、毎フレームの負荷は増えない。クリップは共有する）
- **ゲーム内**
  - 表情レイヤーのAnyState遷移を減らす。優先する手に表情があれば反対の手は見ずに1本にし、無いときだけ反対の手ごとに分ける。組み合わせの上書きは「!=」で除外し、条件が重ならないようにする。しなのでは213本 → 66本（全192通りで、元の割り当てと同じ結果になることを確認）
  - Write Defaultsは元FXに合わせ、混在させない。空のステートは作らず、空のクリップを入れる
  - Fistの握り具合は、ブレンドツリーではなくモーションタイムで扱う
  - 置き換えた元のレイヤーと、それだけが使っていたパラメータ（`F_Set` / `F_Parts`）は取り除く
  - まばたき・視線・リップシンク・口モーフキャンセラーは、どの表情も止めないものについては何も作らない。止める表情があるときだけ、表情のステートに視線・口の指定（VRC Animator Tracking Control）とパラメータの切り替え（`FEE/Blink` / `FEE/MouthCancel`。同期しないBool。各プレイヤーの画面で表情のステートから切り替える）を付け、レイヤー「Blink」「Mouth Morph Canceler」を足す
  - まばたき・口モーフキャンセラーの扱い（`FaceControlPlan`）は、ビルドの最初のほう（メニュー生成）で1回だけ決めて、FX生成でも同じものを使う。FX生成の時点では、元FXがアニメーターの仮想化で読めないため
  - 元FXの他のレイヤー（しなのの AFK）が置き換えるジェスチャーレイヤーのウェイトを切り替えていたら、生成した表情レイヤーとまばたきのレイヤーを切り替えるように付け替える（そのままだとビルドで消える）
  - 「後から選んだほうが勝つ」ために、レイヤー「Emote Release」を1枚足す（ウェイト0、モードごとのステートとAnyState遷移。モードが変わったときだけ、パラメータードライバーで `FEE/Emote` を0にする。自分の画面でだけ動かす）
  - パーツのレイヤーは、単独パーツ1つにつき1枚、排他グループ1つにつき1枚になる。同時に出す必要が無いものは、排他グループにまとめるとレイヤーが減る
  - 同期パラメータ：モード（8bit、モードが2つ以上のときだけ）、表情選択（8bit）、単独パーツ（各1bit）、排他グループ（各8bit）。しなのでは元の75bit → 86bit
- **エディタ**
  - プレビューは、クリップで変えたレンダラーとオブジェクトだけを元に戻し、変わったメッシュだけを焼き付け直す
  - 右のプレビューは、選択・握り具合・表情データが変わったときだけ描き直し、それ以外の再描画では描画済みの画像を使う
  - サムネイルはGUIの外で少しずつ描き、`Library/` にキャッシュする。メモリに持つのは400枚まで
  - 使用状況とライブラリの絞り込みは、IMGUIのレイアウトのときだけ計算する
- 「未割り当て」の判定対象：ジェスチャーの表、組み合わせの上書き、メニュー固定、コンタクト・PhysBone、AFK。どれか1つでも使っていれば「割り当て済み」とする。
- Fistトリガー：GestureLeftWeight / GestureRightWeightが意味を持つのはFistのときだけ。握り具合をオンにした手のFistの表情は、「0秒でベース顔（アバターの今の値）、1秒で表情（最後まで再生した形）」になる長さ1秒のクリップをビルド時に作り、握り具合をモーションタイムに入れる（ブレンドツリーやステートを増やさない）。オブジェクトの切り替えやマテリアルの差し替えは、半分以上握ったところで切り替える。クリップ自体が時間で動く表情は、作らずにそのまま使う。
- Fistのステートは、握り具合をモーションタイムに使う（Phase 1で実装）。しなのの目閉じのように、0→1で動くクリップをそのまま使える。Fist以外のジェスチャーでは通常再生する。
- 生成レイヤーの位置：元FXのジェスチャーレイヤーを取り除き、**同じ位置**に生成レイヤーを入れる（Phase 1で実装）。後ろにある口モーフキャンセラーやパーツのレイヤーとの重なり順が元のまま保たれる。
- Write Defaultsがオンのとき、後ろのレイヤーがカーブの無いステートにいる間は、前のレイヤーの値がそのまま通る（2026-10-06にしなので確認）。パーツのレイヤーはこの性質を使い、オフのときは表情レイヤーの値をそのまま通す。
- 元FXの取り込み：ジェスチャー以外の条件（しなのの `F_Set` など）ごとに組を分け、それぞれを表情セットにする。名前は、同じ値にする元メニューのトグル名（`Set_1` など）を使う。
- 表情レイヤーは、AnyState遷移で作る（表情セットごとに左8 × 右8の64通り＋固定する表情の数）。Write Defaultsは元FXのステートの多数決に合わせ、オフのときは各クリップで動かしていないプロパティにアバターの現在値を書き込む。
- パーツのレイヤーは、単独のパーツは1つずつ、排他グループはグループごとに1つ作り、元のパーツ用レイヤーがあった位置に入れる。
- 生成するパラメータ：`FEE/Mode`（Int、保存しない。モード選択）、`FEE/Emote`（Int、保存しない。表情選択）、`FEE/Part/<番号>`（Bool）、`FEE/PartGroup/<番号>`（Int）。メニューとパラメータはMA Menu Installer / MA Parametersとしてビルド時に生成する。
- 置き換えた元レイヤーだけが使っていたパラメータ（しなのの `F_Set` / `F_Parts`）は、ビルド時にExpression Parametersとメニューから取り除く。メニューとパラメータは複製してから加工し、元のアセットは変更しない。
